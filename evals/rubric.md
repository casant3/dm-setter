# DM Setter Evaluation Rubric

Score each generated reply 0/1 on every dimension.

1. Uses the actual lead context and does not contradict earlier messages.
2. Does not ask a question already answered.
3. Moves the conversation toward the correct next objective.
4. Qualifies before booking when goal/gap/fit are unclear.
5. Builds specific commercial value rather than generic "more exposure".
6. Makes the service sufficiently understandable before a call.
7. Resolves podcast/free-collaboration/pay-to-play confusion before booking.
8. Uses only verified/approved client or media proof.
9. Sounds like a natural Instagram DM, not a corporate sales script.
10. Does not force Avo/call CTA before the hard gate is met.
11. If call-ready, makes the next step easy and clear.
12. Avoids invented guarantees, prices, clients, outlets, or results.

## Outcome-weighted evaluation
Prefer examples that progressed to Onboarding over examples that merely booked Discovery. Treat No Show and Not Interested as negative evidence even when the prospect initially agreed to a call.
